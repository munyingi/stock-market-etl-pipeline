# Stock Market ETL Pipeline

A beginner-friendly data engineering project that demonstrates building a complete ETL pipeline.

## 📊 Project Overview

This project extracts real-time stock market data from Yahoo Finance API, transforms it using Python and pandas, stores it in PostgreSQL, and provides SQL analytics queries.

### What You'll Learn
- API integration with Python
- Data extraction and transformation
- Database design and SQL
- ETL pipeline automation
- Data quality and validation

## 🛠️ Tech Stack

- **Language**: Python 3.9+
- **Data Source**: Yahoo Finance API (yfinance)
- **Database**: PostgreSQL
- **Libraries**: pandas, psycopg2, yfinance

## ⚡ Quick Start

1. Install dependencies: `pip install -r requirements.txt`
2. Configure database: Edit `config/db_config.py`
3. Run pipeline: `python src/extract.py`
4. Query data: See `sql_queries/analytics.sql`
